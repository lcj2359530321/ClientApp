仿网易云音乐 - 畅听 Android 应用 2025.07 - 2025.10

技术栈：Kotlin + Jetpack Compose + MVVM + Retrofit + Room + Media3

独立完成音乐播放、动态社区、短视频、全局搜索、桌面 Widget 等核心功能模块开发

基于 MVVM 架构搭建项目，使用协程+Flow 实现异步数据处理，提升应用流畅度与稳定性

集成 Retrofit+OkHttp 实现网络请求，Room+DataStore 完成本地数据存储与管理

引入 Coil、Paging3、Lottie 等开源库，优化图片加载、分页与交互体验
